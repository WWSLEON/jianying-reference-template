# 剪映参考复刻模板

交付可打开的剪映草稿与原生导出预览。保留用户明确的照片、声音、画幅和复刻范围；先用最快的可靠路线，仍完成实际验收。

## 选择路线

1. 用 `lookup` 查询参考指纹。命中本人已验收案例后检查最终稿、素材、备份仍存在，资源包仍可用。相似标题不能证明是同款；用户明确沿用某已知款式时也可复用相应案例。
2. **同款换图：** 通过剪映当前版本提供的复制草稿/另存功能创建独立稿，替换全部同源照片引用，保留原字幕、声音、转场和关键帧；只复查新图裁切、缩放边界和依赖高光的效果，随后导出。
3. **新参考：** 用 `prepare` 一次取得帧率、帧数、分镜图、稳定照片和原声，再只补变化点附近的帧。可把拆镜、资源审计、字幕资产分给不同代理，只有主代理控制 UI。

公开案例索引初始为空。别人的个人工程和案例不会随技能安装；不要假定另一个账号已有已验收模板。

## 新参考的高效制作

- 用一份表记录时间窗、照片运动、字幕、资源候选和验证状态，先完成能直接判断的部分。
- 先查 `resources`，再对未知或失效候选回剪映库准确检索。分清名称命中、官方ID/包指纹确认、当前机器渲染通过、与当前参考视觉匹配；它们不是同一证据。
- 最难效果先做约2–4秒原生小样，一次覆盖进入、峰值、恢复及字幕层级。动态效果先检查独立特效轨的参数关键帧，避免先改官方资源脚本。相关经验见 [原生工作流](references/native-workflow.md)。
- 连续两次观测不支持同一假设就换机制或查绑定，不围绕错误机制无限调强度。未解决的差异不能报为通过。
- 字体先用可用的剪映图搜或已验证字体；先验证一组代表字形，再铺全部字幕。只需保留原文字时，可用有依据的透明字形图层方案，披露不能直接键入改词，并保留可编辑文字备用。
- 小样通过后完成一个主工程；参数修正优先在原生 UI 进行。只有隔离未知机制才另建短试稿，不为每次调整整片新建工程。
- 用户要求照片缩放时变换照片本身，按新图宽高比计算覆盖画幅下限，避免露边。保持参考原始规格；提高分辨率前验证像素半径类效果是否改变。

## 执行边界与验收

- 优先发现当前环境的剪映能力。可用原生 UI 完成；如已有兼容草稿生成器则按其说明创建独立稿。本技能不要求作者电脑上的路径、虚拟环境或私有生成器。
- 保存过的剪映工程可能加密。保留原件，不解析覆盖；UI前JSON蓝图可能缺少最终参数关键帧，不能当成最终等价稿。
- 登记索引时先正常退出剪映并检查进程，不能杀进程或与应用并发写索引。首页已实际发现新稿则直接打开验收。无法可靠自动生成时走原生 UI，而不是宣称只写JSON便已完成。
- 修正某一段只验收变化窗口，已通过部分锁定。通常一次难点小样导出加一次最终导出；出现实质缺陷才补充导出，不把次数目标当成跳过验收的上限。
- 最终从剪映原生导出，用 `verify --decode` 核对技术属性，另看变化段的入口、峰值、中间、出口。不同照片的纹理/高光不宜只用跨图高频数值判定虚焦强度。
- 保存最终原生备份和实际 UI 参数；记录阶段耗时、检索/试稿/导出次数及失败原因，以实际数据改进，不承诺未经验证的完成分钟数。
- 最终提供预览、草稿位置及必要限制。未获得原工程时，不证明原作者所有原始资源ID或逐像素完全一致；不默认公开发布视频。

## 辅助工具与本地索引

使用当前技能目录下 `scripts/template_tool.py`。Python3.10+，`prepare` 需要 `requirements.txt` 中的 Pillow；FFmpeg/ffprobe 由命令参数、环境变量、PATH 或可选的 `JY_EDITOR_SKILL/bin` 提供。

```text
template_tool.py lookup --reference /path/reference.mp4
template_tool.py prepare --reference /path/reference.mp4 --photo /path/photo.jpg --out /path/new-workspace
template_tool.py resources --query 虚焦
template_tool.py verify --video /path/export.mp4 --reference /path/reference.mp4 --decode --out /path/verification.json
template_tool.py snapshot --draft /path/native-draft --out /path/new-backup
```

工具不会操作剪映、注册草稿、解密原生稿、自动下载效果或替代原生导出。`current_availability.reprobe_required` 为true时只做针对性原生核验，资源候选不代表视觉同款。

索引读取顺序：`JY_CASE_INDEX` / `JY_RESOURCE_REGISTRY` → `references/*.local.json` → 公开索引。个人路径、照片指纹、案例和验收记录只放未跟踪的本地索引及任务目录。公共候选表见 [resource-registry.json](references/resource-registry.json)，初始案例表见 [case-index.json](references/case-index.json)。
