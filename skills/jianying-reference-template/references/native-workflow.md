# 原生剪映的已知操作经验

以下是 macOS 剪映专业版11.6.0(490)的一次实际验收经验。接收方需检查自己版本、资源和原生渲染，不把历史观察当新参考的验收结论。

## 效果与关键帧

- 同一官方效果，绑定在照片片段内时参数可能无关键帧菱形，放在独立紫色特效轨后则可能提供参数关键帧。需要动态半径时先检查独立轨。
- 官方“光斑虚焦”包含清晰→模糊动画。一次验收使用独立轨提前预热，大小0保持照片清晰，在目标失焦帧把大小升到95，再逐渐降至5，退出效果后清晰；速度UI100对应观察到的2倍速度。
- 示例换算：若某版本内置动画约1.666667秒到峰、速度倍率2，则预热约0.833333秒。用实际帧率计算起点并检查seek/导出；不要把某次模板的固定帧号套给其他参考。
- 字幕需要保持清晰时验证作用对象/层级。一次观察中效果render11000、字幕PNG15010保持字幕清晰，新工程仍需用代表字幕测试。
- 弱圆环散景和大平滑圆盘虚焦不是同一机制。“亮点模糊”只适合较弱散景；稀疏核不断放大会出现点阵。不同照片高光不同，不能只用跨图高频比决定强度。
- 曾观察到私有Lua曲线未被运行时采用、全本地UUID资源未渲染。不要先走资源改写或修改全局官方缓存；优先用官方包与原生参数。

## UI与导出

- 使用当前环境提供的应用控制工具；按工具文档刷新状态后取索引/坐标。窗口尺寸和时间线缩放会变化，不硬编码旧坐标。
- Qt AX按钮有时只聚焦/悬停，无变化时按新截图使用坐标或可见键盘操作。“文件→导出”菜单是一条可验证替代路径。
- user changed/Computer Use not active时先刷新；操作后检查实际状态，导出已开始不要反复点击。
- 编辑窗口正常退出后，首页进程可能仍运行。登记前检查进程，必要时首页再正常退出，不强杀、不并发写索引。
- 许多同目录图片需要链接时，尝试原生文件选择框的文件夹自动匹配；中文路径可用工具支持的setValue。
- 导出确认分辨率、帧率、MP4、音轨和额外AI开关。单独“音频导出”是另存音频；MP4音轨不依赖该选项。不要误勾云备份、分享或发布。
- 只把实际导出成功与MP4验证当完成证据，随后关闭成功面板。

## 复用与文件

- 最终加密原生稿与打开前蓝图分别保存；前者可能包含仅在UI创建的效果参数关键帧。不能用旧蓝图覆盖最终保存稿。
- 通过应用提供的复制草稿/另存功能创建独立稿后换图。没有该功能时评估可用生成器与明确的UI补点路线，不猜测加密JSON。
- 草稿备份仍可能引用外部素材，snapshot不是全素材可移植包。
- 帧时间使用有理数。若微秒floor导致末帧缺失，可将终点存为ceil(总帧数×1e6/fps)后再验证，不固定给所有项目加同一个余量，不额外延长原声。
